# Agent Lab RFCs

RFCs record the most coherent contract supported by current implementation
evidence. They are not a substitute for steel threads.

| RFC | Title | Status |
| --- | --- | --- |
| [0001](0001-product-thesis.md) | Product thesis | Provisional |
| [0002](0002-steel-thread-method.md) | Steel-thread method | Provisional |

An RFC may begin as provisional before implementation. Promotion requires a
named evidence boundary and explicit review of the gap between the proposal and
observed behavior.
